# Fontgen Studio

Редактор и собственная обучаемая модель генерации векторных шрифтов по текстовому промпту. React-интерфейс тестирует набор, кернинг и трекинг, а также экспортирует OTF/TTF и текущую тестовую строку в SVG.

Модель находится в `model/`. Во время inference она получает промпт, Unicode-символ и параметры начертания, а затем с нуля предсказывает последовательность Bézier-команд. Исходный глиф из Google Fonts ей не передаётся. Открытые шрифты используются только как обучающий корпус.

## Запуск

```bash
npm install
npm run dev
```

Сборка для GitHub Pages:

```bash
npm run build
```

Папка `dist` готова к публикации. В Vite установлен относительный `base`, поэтому проект работает и в подпапке GitHub Pages. Для вызова обученной модели перед сборкой задайте `VITE_MODEL_API_URL`.

## GitHub Pages

Проект публикуется workflow-файлом `.github/workflows/deploy-pages.yml`: при каждом push в `main` GitHub устанавливает зависимости, выполняет production-сборку и публикует содержимое `dist`. URL inference-сервиса читается из GitHub Actions variable `MODEL_API_URL`.

Один раз откройте в репозитории **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**. Публикация исходников из корня ветки не подходит: браузер не может выполнить исходный файл `src/main.tsx` без Vite-сборки.

## Два процесса

- `npm run dev` запускает редактор. Без `VITE_MODEL_API_URL` он показывает старый контурный прототип, прямо помеченный `NOT AI OUTPUT`; кнопка генерации не выдаёт его за результат модели.
- Python-пакет в `model/` готовит OFL-датасет, обучает prompt-conditioned Transformer и запускает API. Полная инструкция — в `model/README.md`, архитектура — в `docs/MODEL_ARCHITECTURE.md`.

GitHub Pages не может выполнять PyTorch/GPU inference. Статический сайт и модельный API разворачиваются отдельно. Без обученного checkpoint API намеренно возвращает `503`, а не подставляет существующую гарнитуру.

## Лицензии

Каждый файл обучающего корпуса должен иметь проверенную лицензию и запись о происхождении. Встроенные демонстрационные шрифты распространяются по SIL Open Font License 1.1; копия находится в `public/fonts/OFL.txt`.
