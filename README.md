# Fontgen Studio

Локальный генератор шрифтов по текстовому промпту. Проект использует открытые базовые гарнитуры Google Fonts, меняет реальные контуры глифов в браузере и экспортирует результат в SVG, OTF и TTF.

## Запуск

```bash
npm install
npm run dev
```

Сборка для GitHub Pages:

```bash
npm run build
```

Папка `dist` готова к публикации. В Vite установлен относительный `base`, поэтому проект работает и в подпапке GitHub Pages.

## GitHub Pages

Проект публикуется workflow-файлом `.github/workflows/deploy-pages.yml`: при каждом push в `main` GitHub устанавливает зависимости, выполняет production-сборку и публикует содержимое `dist`.

Один раз откройте в репозитории **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**. Публикация исходников из корня ветки не подходит: браузер не может выполнить исходный файл `src/main.tsx` без Vite-сборки.

## Как работает генерация

Промпт разбирается локально: ключевые слова определяют классификацию, базовую гарнитуру, пропорции, наклон и характер. После этого Fontgen преобразует контуры исходного OFL-шрифта, пересчитывает advance width и применяет пользовательские пары кернинга. Никакие тексты или файлы не отправляются на сервер.

Генеративная модель здесь параметрическая, а не нейросетевая: она воспроизводима, работает офлайн и сразу выдаёт валидные файлы шрифта. Для production-качества результат всё равно стоит проверить в FontBakery и вручную доработать диакритику, хинтинг и пары для нужных языков.

## Лицензии

Исходные шрифты распространяются по SIL Open Font License 1.1. Производные шрифты получают новое имя и должны сохранять условия OFL. Копия лицензии находится в `public/fonts/OFL.txt`.
