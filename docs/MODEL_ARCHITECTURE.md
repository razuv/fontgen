# Собственная генеративная модель Fontgen

## Цель

Генерировать новую согласованную гарнитуру по текстовому описанию без передачи исходных глифов модели во время inference. Открытые шрифты используются только как обучающий корпус.

## Почему текущий браузерный движок не подходит

Текущий `src/fontEngine.ts` получает готовые контуры и геометрически преобразует их. Это быстрый интерактивный прототип редактора, но не генеративная модель. Увеличение числа шрифтов или усложнение деформации не устранит это ограничение.

## Архитектура

1. **Prompt encoder.** Обучаемый byte-level Transformer понимает русские и английские описания без внешнего API.
2. **Family latent.** Один вектор стиля используется для всех символов семьи и отвечает за согласованность пропорций, терминалов и пластики.
3. **Glyph content.** Unicode embedding сообщает, какой символ нужно построить, но не содержит чужого контура.
4. **Vector decoder.** Causal Transformer предсказывает последовательность команд `M/L/Q/C/Z` и координаты контрольных точек.
5. **Typography controls.** Вес, ширина, контраст, скругление и наклон входят в conditioning модели; начертания генерируются как связанные значения одной семьи.
6. **Losses.** Command CE + coordinate Smooth L1 в v0; затем raster/perceptual loss, family-consistency loss и anti-copy nearest-neighbor penalty.

## Данные

- только лицензии, разрешающие обучение и производные результаты; происхождение каждого файла хранится в manifest;
- нормализация в 1000 UPM, декомпозиция компонентов и единый формат контурных команд;
- train/validation/test делятся по семьям, а не по отдельным глифам;
- параметры для автоматических подписей извлекаются из OS/2 и геометрических измерений; затем нужен вручную проверенный набор естественных русских/английских описаний;
- первый charset: Basic Latin, русская кириллица, цифры и основная пунктуация.

## Развёртывание

GitHub Pages обслуживает React-интерфейс. Отдельный GPU API загружает чекпойнт, создаёт job и возвращает массив новых контуров. Интерфейс собирает их в SVG/TTF/OTF. Ключ YoFont не нужен.

## Этапы

1. v0 — outline auto-regression и smoke-check на малом корпусе.
2. v0.2 — полноценный OFL-корпус, family split, topology repair.
3. v0.5 — differentiable raster loss и улучшение визуальной гладкости.
4. v1 — contrastive prompt/style alignment, несколько связанных начертаний и production inference API.
